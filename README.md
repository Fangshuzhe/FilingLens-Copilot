# FilingLens Copilot

Evidence-first annual report research copilot.

FilingLens Copilot 将上市公司年报转化为有出处、可追问、可比较、可导出的研究结论。

核心原则：

> 每个关键结论都能回到年报原文，每个数字都由程序计算。

## 项目状态

产品设计与 MVP 方案已完成。

## 文档

- [产品方案](企业年报研究Copilot项目方案.md)

## MVP 方向

- 年报解析与页码保留
- 自动生成公司研究底稿
- 带原文证据的问答
- 引用校验与证据不足拒答
- 研究板与公司一页纸导出

## 产品边界

本项目提供企业研究辅助，不提供股票买卖建议。
